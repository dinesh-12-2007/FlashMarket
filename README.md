# ⚡ FlashMarket

A full-featured e-commerce web application built with **Python** and **Flask**, following the freeCodeCamp Python Web Development curriculum.

---

## 🚀 Features

- 🔐 **User Authentication:** Secure registration, login, and logout using `Flask-Login` and password hashing (`Bcrypt`).
- 🛍️ **Marketplace Dashboard:** Browse available items with pricing, detailed descriptions, and barcodes.
- 💳 **Buy & Sell Items:** Authenticated users can list their own items for sale or purchase items using their account budget.
- 💬 **Flash Notifications:** Real-time feedback for user actions (successful login, errors, insufficient funds, etc.).
- 🎨 **Responsive UI:** Clean design styled with HTML, CSS, and Bootstrap templates.

---

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **Database:** SQLite, Flask-SQLAlchemy (ORM)
- **Forms & Validation:** Flask-WTF, WTForms
- **Authentication & Security:** Flask-Login, Flask-Bcrypt
- **Frontend:** HTML5, CSS3, Bootstrap 4/5
